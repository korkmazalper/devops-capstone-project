# devops-capstone-project

## Overview
This repository contains the DevOps Capstone Project for building and deploying the **Customer Accounts** microservice. The goal of this project is to simulate a real-world Agile software development lifecycle, incorporating cloud-native principles, automated testing, and CI/CD practices.

## Project Details
- **Project Name:** devops-capstone-project
- **Service:** Customer Accounts Microservice
- **Methodology:** Agile / Scrum

## Repository Structure & Agile Planning
- **Agile Management:** Managed via GitHub Projects Kanban board tracking User Stories through Sprints.
- **CI/CD & Microservices:** Implements RESTful APIs, automated test suites, containerization, and pipeline deployment.
